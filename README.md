# BT25 - Bootstrap Responsive Gallery

Bài tập tạo gallery ảnh responsive bằng Bootstrap Grid System.

## Yêu cầu đã thực hiện
- `container`
- `row`
- `col-12`: Mobile hiển thị 1 ảnh mỗi dòng
- `col-sm-6`: Tablet hiển thị 2 ảnh mỗi dòng
- `col-lg-3`: Desktop hiển thị 4 ảnh mỗi dòng
- Sử dụng `g-4`, `card`, `img-fluid`, `shadow-sm`

## Cách chạy
Mở `index.html` bằng trình duyệt hoặc Live Server.
